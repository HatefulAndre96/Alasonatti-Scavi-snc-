Come impostarla sull'iPhone

  1. Tocca Scarica (o Salva in File): il file finisce in File → Download.
  2. Apri l'app File e tocca la suoneria per aprirla.
  3. Tocca Condividi (il quadrato con la freccia) e scegli Usa come suoneria. Se non lo vedi, scorri o tocca Altro.
  4. Conferma in Impostazioni. Fatto, ora suona.

La versione di iOS la trovi in Impostazioni → Generali → Info. iPhone 11 e successivi possono aggiornare a iOS 26 da Impostazioni → Generali → Aggiornamento software.

  1. Scarica la suoneria (finisce in File → Download).
  2. Installa GarageBand dall'App Store (gratis, è di Apple).
  3. Apri GarageBand, crea un brano nuovo e scegli Registratore audio.
  4. Tocca l'icona della vista tracce (i mattoncini, in alto a sinistra).
  5. Tocca l'icona loop (in alto a destra) → scheda File → Sfoglia gli elementi dall'app File → scegli la suoneria.
  6. Tieni premuto il file e trascinalo all'inizio della traccia.
  7. Tocca + (in alto a destra sopra la traccia) → Sezione A → attiva Automatico, così non viene tagliata.
  8. Tocca la freccia ▾ in alto a sinistra → I miei brani.
  9. Tieni premuto il progetto → Condividi → Suoneria → Esporta → Usa suono come… → Suoneria standard.

I nomi delle voci possono cambiare un po' tra versioni di GarageBand.

Consiglio onesto: aggiornare a iOS 26 ti risparmia tutto questo giro. Su iPhone 11 e successivi è gratis.
